# Ziggurat

Ziggurat - simple pet project.

## Build and run

    zig build                       # -> zig-out/bin/ziggurat
    zig build run -- --version      # pass arguments after `--`
    zig build test                  # unit tests

Requires Zig 0.17.0 (`build.zig.zon` `.minimum_zig_version`); no dependencies.
